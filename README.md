## ✨ Features

| Feature | Description |
|---|---|
| 🧺 **Recipe Generator** | Enter ingredients, get a full AI-generated recipe |
| 🔍 **Search by Dish** | Look up any dish by name |
| 💪 **Fitness Mode** | Meal suggestions based on fitness goals (muscle gain, fat loss, endurance) |
| 🏥 **Remedy Kitchen** | Food-based suggestions for common health conditions |
| 📊 **Nutrition Breakdown** | Calories, protein, carbs, fats, fiber per serving |
| 🌍 **Cuisine & Diet Filters** | Indian, Italian, Mexican, Vegan, Keto, Gluten-Free & more |
| ⭐ **Favorites & History** | Save and revisit recent recipes (localStorage) |
| 📋 **Copy to Clipboard** | Export formatted recipe text instantly |
| 🌙 **Dark Mode** | Easy on the eyes, day or night |

## 🛠️ Tech Stack

**Frontend** — HTML5, CSS3, Vanilla JavaScript
**Backend** — Node.js, Express.js
**AI** — Groq API (Llama 3.3 70B)
**Deployment** — Railway + GitHub (CI/CD)

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/ai-recipe-generator.git
cd ai-recipe-generator
npm install
```

Create a `.env` file in the root:
GROQ_API_KEY=your_groq_api_key

PORT=5000
Run it:

```bash
node server.js
```

Visit `http://localhost:5000` 🎉
